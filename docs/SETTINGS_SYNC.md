# 設定跨裝置同步與回報對象快捷選擇

登入同一同步帳號後，App 自動同步深色模式、預設起點、一般客上／客下回報對象、固定乘客回報對照、地點簡稱、提醒關鍵字、指定群組／發送者提醒，以及 AI 供應商、模型、備援與提示詞。

API 金鑰及 Message 連線憑證留在每台裝置的加密儲存；系統通知權限與聲音由各手機設定。同步 AI 設定會保留接收裝置自己的金鑰。

Firestore 使用 `users/{uid}/settings/app_<preferences file>_<key>`，一項設定一份文件，與既有 `rental_plan` 分開。同項設定採最後提交版本；不同項不會整包覆蓋。首次登入先接收帳號既有設定，雲端缺少的本機設定才透過交易補上。修改的待送內容依 uid 保留在本機；離線後重開 App 仍能在帳號連線後送出。登出時停止設定監聽。

雲端規則需允許使用者讀寫自己的 `users/{uid}/settings`。設定頁會顯示設定連線／同步失敗狀態。雲端部署與兩台實機互傳需另外驗證。

行程編輯的回報對象空白時，欄位右側顯示快捷選擇按鈕。先列固定乘客姓名與回報對象，再列依近期行程排序的歷史對象；去除空白及重複群組。選擇後填入欄位，按行程儲存才保存，不會發送任何訊息。
